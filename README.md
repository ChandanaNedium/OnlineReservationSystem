# OnlineReservationSystem

The Online Reservation System is a Java console-based application that allows users to reserve and cancel train tickets. The system simplifies the reservation process and maintains booking details.

//Features

Login authentication

Train ticket reservation

Automatic train name display

Ticket cancellation using PNR

Menu-driven interface

//Technologies Used

Java

Scanner class

Console-based interface

//How to Run

Compile the program

javac OnlineReservationSystem.java

Run the program

java OnlineReservationSystem

//Sample Output
===== ONLINE RESERVATION SYSTEM =====
1 Reserve Ticket
2 Cancel Ticket
3 Exit
